# Tau Solutions

Одностраничный сайт студии цифровых продуктов. Портфолио реальных проектов, направления работы, подход и прямой контакт для обсуждения задач.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm install
npm run dev
```

## Стек

- React 19, TypeScript strict, Vite 8.
- Zustand 5: фильтрация проектов, выбранный кейс, мобильная навигация.
- Feature-Sliced Design 2.1: app → pages → widgets → features → entities → shared.
- Radix UI Dialog, Tabs, Slot: готовое интерактивное поведение и доступность.
- Motion: появление заголовка и экранов по слоям, параллакс, TiltCard с бликом, переходы фильтров, вход и выход модальных окон, орбитальные импульсы и индикатор прокрутки; reduced motion.
- Phosphor Icons, локальные Unbounded Variable и Onest Variable, CSS с дизайн токенами.
- Vitest, Testing Library, Happy DOM; ESLint с boundaries, Steiger, jscpd.

## Проверки

```sh
npm run check
npm run build
npm audit
```

`npm run check` запускает линтер, TypeScript, FSD проверки, тесты и поиск дублирования с порогом 1.2%. Витрина презентационных компонентов: `/dev/components`, только при `npm run dev`.

## Контент

В портфолио четыре проекта: TAU «Архитектор жизни», mini app Яны Алфимовой, Automata Lab и локальная игра «Линия обороны». Описания сверены с локальными исходниками и документацией. Превью используют реальные экраны: тестовые снимки TAU, приложение Яны, рабочую модель лаборатории и матч игры на четыре места. «Линия обороны» — новое имя игры в этом портфолио.

У TAU указан фактический статус разработки. Демонстрационные данные на экранах не выдаются за подтверждённые клиентские результаты. Кнопки связи ведут на https://t.me/desmond333. Сайт не отправляет формы, не использует аналитику и не хранит персональные данные.

## Дизайн

В качестве ориентира использован [landing-page-design](https://github.com/elayadesign/ai-design-skills/tree/main/skills/landing-page-design), MIT. По уточнённому брифу выбрана космическая композиция: тёмный фон, холодный свет, орбиты и минимум текста. Заголовки используют Unbounded, основной текст — Onest. Изображение `public/images/orbital-world.webp` создано встроенным инструментом генерации изображений: тёмная планета с ледяной подсветкой, серебристым кольцом и звёздами; левая часть оставлена для текста. Исходный PNG находится рядом. Шрифты и изображение находятся в проекте, внешние CDN не нужны.

В блоке подхода используется `public/images/orbital-process.webp`: орбитальная скульптура с тремя кольцами и светящимся ядром, созданная встроенным генератором изображений на прозрачном фоне. Превью проектов находятся в `public/projects/`, все экранные композиции строятся одним `ProjectArtwork` из конфигурации проекта. Фотографии и интерфейсы исходных приложений не заменяются сгенерированными макетами.

Карта модулей и правила переиспользования: [PROJECT_MAP.md](./PROJECT_MAP.md).
