# Tau Solutions — карта проекта

Обновлено: 2026-10-30.

## Архитектура

FSD 2.1. Импорты направлены app → pages → widgets → features → entities → shared. Слайсы одного слоя изолированы; публичный API каждого слайса — index.ts. Презентационные компоненты не содержат доменных данных. Неиспользуемые слои и сегменты не создаются.

## Реестр переиспользуемых компонентов

| Компонент  | Основа               | Контракт                                                                          | Проверка           |
| ---------- | -------------------- | --------------------------------------------------------------------------------- | ------------------ |
| Action     | Radix Slot           | primary / dark / light / ghost, sm / md, asChild, disabled                        | Action.test.ts     |
| Modal      | Radix Dialog         | dialog / drawer, title, description, trigger, возврат фокуса                      | Modal.test.ts      |
| FilterTabs | Radix Tabs           | Управляемое значение, массив вкладок, клавиатурная навигация                      | FilterTabs.test.ts |
| Brand      | Семантическая ссылка | Светлый и тёмный варианты, доступное название                                     | Brand.test.ts      |
| TiltCard   | Motion               | Наклон от курсора, maxTilt, glare, reduced motion; клавиатура и touch без наклона | TiltCard.test.ts   |

Все компоненты экспортируются через `src/shared/ui/index.ts`, представлены в `/dev/components`. Детали проектов и мобильное меню переиспользуют один Modal с размерами md / lg и вариантами dialog / drawer, анимацией открытия и закрытия. Все CTA используют Action. Проектные превью переиспользуются в карточках, деталях и DEV витрине. TiltCard адаптирован из существующего общего компонента mini app; он не содержит доменных данных. FilterTabs сохраняет Radix ARIA и навигацию, а смена содержимого анимируется через AnimatePresence.

## Состояние и данные

- `features/navigation/model/navigationStore.ts`: открытие мобильного меню.
- `features/project-explorer/model/explorerStore.ts`: фильтр и выбранный проект.
- `entities/project/model/projects.ts`: единственный источник четырёх реальных проектов, описаний, возможностей, технологий, изображений и фильтров. ProjectId отделён от ProjectCategory.
- `shared/config/site.ts`: единственный источник контактной ссылки и пунктов меню.
- `entities/project/ui/ProjectArtwork.tsx`: единая композиция реальных экранов с параметрами проекта. Варианты расположения управляются идентификатором и previewLayout, отдельные копии компонентов под кейсы не создаются.
- Фильтры: все проекты, продукты, mini apps, инструменты, игры. Данные Zustand не сохраняются между сессиями.
- Превью — снимки реальных приложений. TAU использует существующие тестовые эталоны с демонстрационными данными; остальные снимки получены из локальных интерфейсов. Изображения оптимизированы в WebP.
- `public/projects/`: life-desktop / life-mobile, creator-mobile / creator-catalog, lab-desktop, defense-play. Исходные PNG сохранены рядом.
- Блок approach содержит отдельную орбитальную скульптуру orbital-process.webp, а контактная сцена переиспользует orbital-world.webp.
- Motion: появление экранов по слоям при прокрутке, TiltCard с бликом от курсора, анимация фильтров, вход и выход модалок, орбитальные импульсы и индикатор прокрутки в App. Для coarse pointer наклон отключён; все анимации учитывают reduced motion.
- Внешние API, авторизация, база данных и постоянное хранение не используются.

## Контроль качества

Настройки TypeScript, ESLint boundaries, Steiger и структурная проверка переиспользованы из локального react-fsd-starter. Правила запрещают импорты вверх, между слайсами одного слоя, глубокие импорты, вложенные тернарные операторы и legacy каталоги. Vitest проверяет компоненты, фильтры и полный сценарий просмотра проекта. jscpd контролирует порог дублирования 1.2%.
